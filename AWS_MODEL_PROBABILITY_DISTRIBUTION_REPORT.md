## 1. Executive Summary

This report examines the multi-class probability outputs, confidence distributions, and risk scoring equations generated by the authoritative Big Data XGBoost V2 model across live AWS network flows, synthetic attack vectors, and representative benchmark workloads.

Key results:
1. **Benign Flow Probability Concentration:** Live AWS flows show steep probability concentration in the `BENIGN` class ($P \ge 0.997$), with negligible probability mass assigned to attack classes ($\le 0.001$).
2. **Attack Sensitivity:** When characteristic attack features appear (`unique_dst_ports \ge 20` for Port Scan, volumetric burst rates for Traffic Spike, failed auth repetitions for Brute Force), probability mass shifts decisively to the corresponding attack class.
3. **Continuous Risk Calibration:** Continuous risk scores ($0–100$) accurately map model uncertainty and class severity into deterministic policy actions (`Allow`, `Monitor`, `Restrict`, `Block`).

## 4. Continuous Risk Score Calculation

The gateway does not rely merely on hard class labels. It employs a weighted continuous risk scoring formulation:

$$\text{RawRisk} = \sum_{c \in \text{ThreatClasses}} P(c) \cdot W_c \cdot 100$$
$$\text{RiskScore} = \min\left(100, \max\left(0, \text{round}(\text{RawRisk})\right)\right)$$

Where class severity weights $W_c$ are calibrated as:
- $W(\text{TRAFFIC\_SPIKE}) = 1.00$
- $W(\text{BRUTE\_FORCE}) = 0.90$
- $W(\text{PORT\_SCAN}) = 0.85$
- $W(\text{SUSPICIOUS\_TRANSFER}) = 0.80$

### Policy Mapping Thresholds
- **Score $0 - 29$ (`LOW`):** `Allow`
- **Score $30 - 59$ (`MEDIUM`):** `Monitor`
- **Score $60 - 79$ (`HIGH`):** `Restrict` / `Block`
- **Score $80 - 100$ (`CRITICAL`):** `Block`
